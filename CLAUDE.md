# Instrucciones del proyecto

Para **cualquier** video que el usuario pida editar, sigue siempre la skill `edicion-reels` (`.claude/skills/edicion-reels/SKILL.md`). Es la estructura base de todos sus videos: vertical 9:16, solo su voz, **sin música**, todo a **1.3x**, estructura GANCHO → MENSAJE / ESTRUCTURA → CTA → **"SÉ POSITIVO"**.

Cuando el usuario no tenga acceso a su PC, subirá los videos crudos a Google Drive para que se descarguen, revisen y editen desde aquí.
